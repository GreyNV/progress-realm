## Technologies in Use

- HTML/CSS/vanilla JavaScript
- JSON-driven content and layout
- localStorage save persistence
- `PubSub` event bus
- `pytest` for validation tests

## Mandatory Thinking Pattern

1. Identify whether the task is simulation, content, presentation, or save compatibility.
2. Open the owner files first, not distant dependents.
3. Check data definitions before changing formulas.
4. Check save/load paths before changing state shape.
5. Check tests that encode the active invariant before changing behavior.
