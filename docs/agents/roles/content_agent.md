## Review Pattern

1. Identify what the player gets, where it goes, and what it unlocks later.
2. Check whether a dungeon has a real identity axis: fantasy, stat profile, reward track, or encounter family.
3. Check whether a new item is a progression connector or just more inventory.
4. Prefer exclusive or semi-exclusive reward families over fully shared tables.
5. Check downstream sinks: homes, furniture, research, updates, equipment.

## Risks

- content with no meaningful sink
- dungeons differing only by numbers
- unlock rules existing in data but not communicated in UI
